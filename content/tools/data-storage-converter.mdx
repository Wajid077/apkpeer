## How to convert data sizes

1. Type a size in the **Value** box.
2. Choose its unit, for example megabytes.
3. Choose **Decimal** or **Binary** units.
4. See the size in bits, bytes, kilobytes, megabytes, gigabytes and terabytes.

## Decimal vs binary units

There are two ways of counting data sizes, which is a common source of confusion:

| Decimal (SI) | Binary (IEC) |
| --- | --- |
| 1 KB = 1,000 bytes | 1 KiB = 1,024 bytes |
| 1 MB = 1,000 KB | 1 MiB = 1,024 KiB |
| 1 GB = 1,000 MB | 1 GiB = 1,024 MiB |
| 1 TB = 1,000 GB | 1 TiB = 1,024 GiB |

Storage makers, Android and Google Play use **decimal** units. Windows shows sizes in binary units but labels them KB, MB and GB, which is why the same drive can look smaller on a Windows PC.

## Why your phone shows less storage

A phone sold as 128 GB has 128,000,000,000 bytes. In binary units, that's about 119.2 GiB, so a device that counts in binary shows a smaller number. On top of that, the operating system, system apps and reserved space take up several more gigabytes before you install anything.

## App and APK sizes

The size shown on a Play Store listing is the download size. Once installed, an app usually takes more space, because it unpacks files and builds a cache as you use it. Games often download extra data on first launch, sometimes several gigabytes. When storage is tight, convert the download size here and compare it with your free space under **Settings → Storage**.

## Bits vs bytes

Internet speeds are measured in bits per second (Mbps), while file sizes are in bytes (MB). There are 8 bits in a byte, so a 100 Mbps connection downloads about 12.5 MB per second at best.
