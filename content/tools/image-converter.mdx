## How to convert an image

1. Tap **Choose images** or drag your files onto the box. You can add several at once.
2. Pick the format you want under **Convert to**: JPG, PNG or WebP.
3. For JPG or WebP, set the quality. For JPG, you can also choose the color that replaces transparent areas.
4. Tap **Convert**, then **Download** next to each result.

The list shows each image's new size, so you can see straight away whether the converted file is smaller or bigger than the original.

## Which format should you choose?

| Format | Best for | Transparency | File size |
| --- | --- | --- | --- |
| JPG | Photos, sharing, email, upload forms | No | Small |
| PNG | Screenshots, logos, text, images you'll edit again | Yes | Large |
| WebP | Websites and apps, modern browsers | Yes | Smallest |

If you're not sure, choose **JPG** for photos and **PNG** for screenshots and graphics with sharp edges or text. WebP gives the smallest files and is supported by all current browsers and Android, but some older apps, editors and upload forms still reject it.

## How it works, and why nothing is uploaded

Your browser already knows how to decode and encode these image formats. This tool opens each file in your browser, draws it onto an invisible canvas, and saves it again in the format you chose. The files never travel over the internet, so it's fast even on a slow connection and safe for private photos.

A side effect is that metadata such as camera details and GPS location is removed from the converted file. If you need to keep that information, keep the original file too.

For more advanced editing, such as cropping, color correction or retouching, try a dedicated editor like <AppLink slug="snapseed">Snapseed</AppLink> on Android.
