## How to resize an image

1. Tap **Choose images** or drag your files onto the box. The first image's size is shown and filled in.
2. Choose **Pixels** to set an exact width and height, or **Percentage** to scale by a fixed amount.
3. With **Lock aspect ratio** on, change only the width and the height follows automatically.
4. Tap **Resize**, then download each image.

When you resize several images with the aspect ratio locked, each one keeps its own proportions and is scaled to the width you set.

## Common sizes

| Use | Suggested size |
| --- | --- |
| Profile picture | Square, 400–1080 px |
| Instagram post | 1080 × 1080 (square) or 1080 × 1350 (portrait) |
| Story or Reel cover | 1080 × 1920 |
| Website hero image | 1600–2000 px wide |
| Email attachment | 1200–1600 px on the longest side |
| Blog or article image | 1200 px wide |

Platforms change their recommendations from time to time, so check the current guidance if a size matters for something important.

## Resizing vs compressing

Resizing changes how many pixels an image has. Compressing changes how efficiently those pixels are stored. Resizing a 4000-pixel phone photo down to 1600 pixels removes about 84% of its pixels, which usually cuts the file size dramatically before any compression. For the smallest files, resize first, then use the [image compressor](/tools/image-compressor).

## Making images bigger

You can set a larger size, but enlarging can't create detail that isn't there, so the result looks soft. Resizing works best for making images smaller. If you need a sharper large image, start from a higher-resolution original.

## Format and quality

The resizer keeps JPG and WebP in their original format and saves other formats as PNG. The quality slider applies to JPG and WebP output. To change the format at the same time, resize first and then use the [image converter](/tools/image-converter).

## Private and offline-friendly

Images are resized in your browser and never uploaded, and the tool keeps working without a connection once the page has loaded.
