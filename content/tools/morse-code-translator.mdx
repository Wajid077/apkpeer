## How to translate Morse code

1. Choose **Text → Morse** or **Morse → text**.
2. Type or paste your message.
3. Copy the result.

When writing Morse, use a **space between letters** and a **slash between words**: `.... . .-.. .-.. --- / .-- --- .-. .-.. -..` is "HELLO WORLD".

## The Morse alphabet

| Letter | Code | Letter | Code | Letter | Code |
| --- | --- | --- | --- | --- | --- |
| A | .- | J | .--- | S | ... |
| B | -... | K | -.- | T | - |
| C | -.-. | L | .-.. | U | ..- |
| D | -.. | M | -- | V | ...- |
| E | . | N | -. | W | .-- |
| F | ..-. | O | --- | X | -..- |
| G | --. | P | .--. | Y | -.-- |
| H | .... | Q | --.- | Z | --.. |
| I | .. | R | .-. | | |

Numbers use five symbols each, from `-----` for 0 to `----.` for 9. The translator also supports common punctuation such as full stops, commas, question marks and @.

## Timing when sending Morse

Morse is a code of timing as much as symbols. A dash lasts three times as long as a dot, the gap between parts of a letter is one dot, the gap between letters is three dots, and the gap between words is seven dots. Learners usually start by listening to letters at full speed with longer gaps between them, which helps recognize each letter's rhythm.

## Where Morse is still used

Morse code is still used by amateur radio operators, in aviation and maritime navigation beacons, and in escape rooms and puzzles. It's also an accessibility tool: some people with limited mobility use Morse input to type on phones, and Android's Gboard keyboard supports a Morse code layout.
