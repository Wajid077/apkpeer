## How to make a QR code

1. Choose **Link or text** for a website, message or any text, or **Wi-Fi** to share a network.
2. Type or paste your content. For Wi-Fi, enter the network name, password and security type exactly as they appear in your router settings.
3. Adjust the size, colors and error correction if you want to. The preview updates instantly.
4. Tap **Download PNG** for screens and documents, or **SVG** for printing and design work.

Test the code with your phone's camera before you print it or share it widely. On Android, the camera app or Google Lens reads QR codes directly; on iPhone, the built-in camera does too.

## What can you put in a QR code?

A QR code simply stores text. Phones recognise certain kinds of text and act on them:

| Content | What the phone does |
| --- | --- |
| A web address (https://…) | Offers to open the page |
| Wi-Fi details | Offers to join the network without typing the password |
| Plain text | Shows the text so it can be copied |

Short content makes a simpler code that scans faster and from further away. If your link is very long, use a link shortener or a shorter page address first.

## Choosing colors and error correction

QR scanners need contrast. Dark code on a light background is the safest choice; light code on a dark background confuses some older scanners. Bright brand colors work if they're still clearly darker than the background.

Error correction lets a code still scan when part of it is damaged, dirty or covered. **Medium** suits most uses. Choose **High** if you plan to put a logo over the middle of a printed code, but expect a denser pattern.

## Printing tips

- Print the code at least 2 cm (about 0.8 inches) wide, and bigger for posters people will scan from a distance.
- Leave a clear margin around the code; the white border is part of what scanners look for.
- Use the SVG download for print shops and design apps such as <AppLink slug="canva">Canva</AppLink>, so the code stays sharp at any size.

## Are your QR codes private?

Yes. The code is generated by your browser and the content never reaches our server. Unlike some free generators, there's no redirect link hidden inside the code, so it doesn't depend on any service staying online and it never expires.
