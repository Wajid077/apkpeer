## How to pick a random name

1. Paste your names or items into the box, one per line or separated by commas.
2. Set how many **Winners** to pick.
3. Tap **Pick winner**. To put everyone in a random order instead, tap **Shuffle whole list**.

The tool shows how many entries it found, so you can check nothing was missed. Blank lines are ignored.

## How the draw works

The picker shuffles a copy of your list using the Fisher–Yates algorithm with your browser's secure random number generator, then takes the first names from the shuffled list. That means:

- Every entry has exactly the same chance of being picked.
- Nobody can be picked twice in one draw.
- The result can't be predicted or influenced, including by us.

If someone should have more chances, for example a person with three raffle tickets, simply add their name three times.

## Ideas for using it

| Situation | Tip |
| --- | --- |
| Social media giveaways | Paste the usernames of everyone who entered |
| Classroom turns | Shuffle the whole list to set the order |
| Team selection | Shuffle, then split the list into groups |
| Secret Santa | Shuffle, then each person gives to the next name on the list |
| Deciding where to eat | Paste the options and pick one |

## Running a fair public giveaway

For giveaways, transparency matters as much as fairness. Show the full list of entries, record your screen while you paste the list and press Pick, or run the draw live. Remove duplicate entries first with [remove duplicate lines](/tools/remove-duplicate-lines) if each person should count once.
