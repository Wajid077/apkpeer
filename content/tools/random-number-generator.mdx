## How to generate random numbers

1. Set the **Minimum** and **Maximum**. Both are included in the range.
2. Set **How many** numbers you want (up to 1,000).
3. Tick **No repeats** if each number should appear only once.
4. Tap **Generate**.

A single result is shown large so it's easy to read out; several results appear as a list you can copy.

## How fair is it?

The generator uses your browser's cryptographically secure random number generator, the same source used for encryption keys. It also avoids a subtle problem in many simple random tools called **modulo bias**, where some numbers come up slightly more often than others because of how random values are squeezed into a range. Here, every number in your range has exactly the same chance.

## Ideas for using it

| Use | Settings |
| --- | --- |
| Roll a die | 1 to 6, 1 number |
| Pick a raffle ticket | 1 to the number of tickets, no repeats |
| Lottery-style picks | The lottery's range and count, no repeats |
| Random sample | 1 to the size of your list, the number of items you need, no repeats |
| Classroom turns | 1 to the number of students |

If your entries are names rather than numbers, the [random name picker](/tools/random-name-picker) lets you paste the list and pick winners directly.

## A note on lotteries

Random number generators can't predict or improve lottery odds: every combination is equally unlikely to win. Use it for fun picks, not as a strategy.
