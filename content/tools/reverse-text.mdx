## How to reverse text

1. Type or paste your text into the **Input** box.
2. Choose what to reverse:
   - **Letters** writes the whole text backwards.
   - **Word order** keeps each word readable but reverses their order on each line.
   - **Line order** flips a list so the last line comes first.
3. Copy the result.

## Examples

| Mode | Input | Result |
| --- | --- | --- |
| Letters | Hello world | dlrow olleH |
| Word order | one two three | three two one |
| Line order | first / second / third | third / second / first |

## What people use it for

- **Palindrome checks.** Reverse a word or phrase and compare it with the original. "Level", "racecar" and "madam" read the same both ways.
- **Puzzles and games.** Backwards text is a simple code for treasure hunts and riddles.
- **Social media.** Reversed or mirrored-looking text stands out in bios and posts.
- **Lists.** Turning a list sorted oldest-first into newest-first is a single tap with Line order.

## Emoji and special characters

Many reverse-text tools break emoji and accented letters into garbled symbols, because those characters are made of more than one hidden code unit. This tool reverses whole characters, so most emoji, accented letters and non-English scripts stay intact. Some complex emoji built from several pieces, such as family or flag emoji, can still change, because they're made of several characters joined together.

## Tips

- Combine it with the [case converter](/tools/case-converter) to make text both backwards and upper case.
